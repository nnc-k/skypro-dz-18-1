# Домашнее задание 18.1: Введение в БД

Учебный проект по Python: работа с базой данных PostgreSQL, создание таблиц и загрузка данных из CSV-файлов.

## Функционал проекта

- Создана база данных `north`.
- Созданы три таблицы: `employees` (сотрудники), `customers` (клиенты), `orders` (заказы).
- Определены связи между таблицами (внешние ключи `FOREIGN KEY`).
- Написан Python-скрипт (`src/main.py`), который подключается к базе данных с помощью библиотеки `psycopg2` и загружает в таблицы данные из CSV-файлов (папка `north_data`).
- Для безопасного хранения паролей используется файл `.env` и библиотека `python-dotenv`.

## Структура проекта

dz_18_1/

## Установка и запуск

1. Установить зависимости:
   poetry install
2. Создать базу данных `north` в PostgreSQL.
3. Выполнить SQL-код из файла `create_tables.sql` в pgAdmin.
4. Создать файл `.env` в корне проекта и заполнить данные для подключения:
   DB_NAME=north
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль
   DB_HOST=localhost
   DB_PORT=5432
5. Запустить скрипт:
   poetry run python src/main.py
